# TikZ 画板

一个无需安装依赖的本地 HTML 绘图工具。双击 `index.html` 即可打开；项目文件都在本目录，离线可用。

## 使用

- 左侧工具栏选择图形，在画布拖拽绘制。选中后可移动、缩放、编辑顶点和属性；支持多选、对齐、图层顺序、撤销与重做。
- 右侧代码会随绘图更新，默认只显示 `tikzpicture` 内的图形语句，可复制或下载 `.tex`。需要完整的 `tikzpicture` 环境时勾选“包含环境”；需要 `\\usepackage`、宏库和颜色定义时勾选“包含依赖”。
- 点击顶部“排版 / 图注”，可选择用 `figure` 环境导出，并设置靠左、居中、靠右、浮动位置、图注位置及引用标签。弹窗提供文档布局预览；开启后会自动包含 `tikzpicture`，依赖仍由“包含依赖”单独控制。普通文字图注会自动转义 LaTeX 特殊字符，同时保留 `$...$` 公式；如需自行编写图注命令，可切换为“LaTeX 代码”。导入带标准 `figure` 包裹的 TikZ 时，这些属性也会读回。
- 点击“导入 / 编辑代码”可粘贴 TikZ 代码或打开 `.tex`、`.tikz`、`.txt` 文件。窗口会显示识别到的图元数量；确认导入后可继续在画布编辑。也可打开当前生成的代码，手动修改后重新导入。
- 内容自动保存在本机浏览器中。

## 可视化导入范围

支持 `\\draw`、`\\fill`、`\\filldraw` 的直线、折线、多边形、矩形、圆、椭圆、单段贝塞尔曲线、`plot coordinates`，以及独立的 `\\node ... at (...) {...};`。可识别常用颜色、线宽、线型、透明度、箭头、圆角和文本样式，以及 `HTML` 格式的 `\\definecolor`。

TikZ 是可编程语言，任意宏、循环、坐标计算与作用域变换无法在这个纯本地画板中完整解释。导入窗口会列出这些语句；它们按原文保留在导出代码中，并在右侧代码面板标红，但不会被错误地画成图形。重新生成代码后请用 LaTeX 编译器检查最终效果。

文本节点中的 `$...$`、`\\(...\\)` 和 `\\[...\\]` 公式使用项目内置的 KaTeX 与字体在画布上方的 HTML 文字层排版，随图形同步移动和缩放。选框和锚点使用排版后的实际浏览器尺寸；公式语法有误时画布显示错误提示，不再显示原始命令。KaTeX 与最终 LaTeX 编译器仍可能在字体和宏支持上有差异。KaTeX 按 MIT 许可证随项目提供，许可证位于 `vendor/katex/LICENSE`。

自定义的 `tikzpicture` 画布选项会保留在导出代码中，但目前不会作用于画布预览。导入完整文档时，画板读取 `tikzpicture` 内容、`HTML` 颜色定义和 `\\usetikzlibrary`；其他导言区设置应在最终 LaTeX 文档中自行保留。

## 文件

- `index.html`：界面
- `styles.css`：样式
- `app.js`：画布交互和 TikZ 导出
- `tikz-import.js`：TikZ 图元解析
- `vendor/katex`：本地公式排版库、样式与字体
