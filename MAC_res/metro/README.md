# Vanilla+ Metro（原版拓展·轻量化地铁系统）

基于 **Minecraft 原版铁轨与矿车**，通过方块拓展、物理优化与逻辑控制，实现一套兼具装饰性与全自动运行能力的地铁系统——不引入任何自定义实体或非原版载具，全部玩法建立在原版矿车与铁轨之上。

> 核心理念：原版轨道，硬核优化，智能控制，现代视觉。

## 版本要求

| 项 | 要求 |
|---|---|
| Minecraft | **1.21**（正式版 1.21.0） |
| 加载器 | **Fabric Loader** ≥ 0.15.11 |
| 前置模组 | **Fabric API**（建议 `0.102.0+1.21` 或更新的 1.21 版本，需自行从 Modrinth / CurseForge 下载） |
| Java | **21**（客户端启动器需切换到 Java 21） |

## 安装步骤

1. 安装 **Fabric** 版 Minecraft 启动器，并创建一个 **1.21** 的 Fabric 版本，确保使用 **Java 21** 启动。
2. 从上方下载「模组主文件」`vanilla-plus-metro-1.0.0.jar`。
3. 另外单独下载一份对应 1.21 的 **Fabric API**（前置模组，本资源包不包含，需自行获取）。
4. 把这两个 `.jar` 文件都放进游戏目录下的 `.minecraft/mods/` 文件夹（没有 `mods` 文件夹就新建一个）。
5. 启动游戏。进入创造模式后：
   - **「红石」物品栏页**能找到本模组的方块：站台核心块 / 屏蔽门 / 闸机 / 线路总控面板 / 信号灯。
   - **「工具」物品栏页**能找到连挂棒、信号配置器、施工法杖。

> 「源码 Jar」不是运行必需的，只是方便查看代码，**不需要**放进 `mods` 文件夹。

## 玩法速览

- **连挂棒**：右键第 1 辆矿车再右键第 2 辆，组成可联动移动的列车；潜行 + 右键可解挂。
- **站台核心块**：铺在铁轨正下方即为一个车站，可交互调节停靠时间、加速度、巡航速度（最高可达 24 m/s，突破原版 8 m/s 限速），以及是否为「终点折返站」。
- **现代屏蔽门**：放在站台核心块附近，列车停稳自动开门、发车前自动关门，玩家无法徒手打开。
- **地铁闸机**：默认关闭挡住通行，消耗绿宝石（车票）或红石信号可开启。
- **线路总控面板**：贴近铁轨右键，自动沿轨道做连通性检测，并统计站台与信号灯数量。
- **现代信号灯 + 信号配置器**：为线路划分闭塞区间，前方有车占用则红灯并让后车自动减速停车，区间空闲则绿灯放行；红灯时输出红石信号，可联动原版机关。
- **施工法杖**：沿多个路点一键生成轨道走廊，支持地面路基 / 隧道 / 高架桥三种样式，自动处理转角与坡道。

## 已知限制

- 站台参数通过动作栏交互式配置，暂无弹窗 GUI。
- 信号闭塞区间以「到下一站台」为界，尚未支持按信号灯细分区段；折返目前是原路「站前折返」。
- 施工法杖转弯仅支持 90°，暂无对角线宽弯或平滑弧线，也暂无撤销/预览功能。
