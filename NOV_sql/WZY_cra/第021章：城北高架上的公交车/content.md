# 第021章 城北高架上的公交车

别回家。

四个字从林砚手腕上浮出来时，江临川也看见了。

他脸上的笑意消失得很快。

周启帆刚离开，走廊里只剩他们两个人。档案室门缝下干干净净，像刚才那撮灰白粉末从来没出现过。

林砚低头看着纱布边缘渗出的红痕。

“什么意思？”

江临川看了一眼楼梯口：“字面意思。”

“家里有事？”

“也可能是回家的路上有事。”

“你知道？”

“我不知道。”江临川说，“但这种提示不是随便出现的。”

林砚拿出手机。

屏幕上有三通未接来电。

唐曼。

刚才他们在档案室附近，手机一直静音。林砚回拨过去，电话接得很快。

“林砚？”唐曼的声音明显松了一口气，“你怎么不接电话？”

“刚才在学校。”林砚说，“怎么了？”

“你爸车坏在城北那边了，我过去给他送备用钥匙。你晚饭自己吃，晚上早点回来。”

城北。

林砚抬头看向江临川。

江临川没有听见电话内容，却从他的表情里看出不对。

“妈。”林砚问，“你现在在哪？”

“刚上公交，过城北高架。”唐曼说，“怎么了？”

林砚的手指猛地收紧。

别回家。

不是让他别回家。

是家里人不在家。

“你坐哪路车？”

“307。”唐曼说，“你问这个干什么？”

307 路。

城北高架。

林砚脑子里忽然闪过章节细纲里还没发生的画面。

不。

他不该知道。

可那个念头像从水底冒出来，带着一股让人窒息的冷意。

公交车。

撞毁。

复原。

“妈。”林砚尽量让声音平稳，“下一站下车。”

唐曼愣了一下：“为什么？”

“你先下车。”

“林砚，你又怎么了？”

公交车里传来报站声。

下一站，城北高架东。

车辆起步，请站稳扶好。

林砚几乎是喊出来：“下车！”

电话那头安静了一瞬。

然后是唐曼压低的声音：“车已经上高架了，下一站还早。你别吓妈妈。”

信号忽然变差。

滋啦。

滋啦。

像有细密的电流穿过听筒。

林砚听见唐曼说：“你爸刚才还说……”

声音断了。

电话挂断。

林砚立刻回拨。

无服务。

他转身就往楼下跑。

江临川在身后骂了一句，跟了上来。

“你去哪？”

“城北高架。”

“你疯了？这种提示不是让你往里冲的。”

林砚没有停。

“我妈在车上。”

江临川的脚步顿了一下。

然后追得更快。

他们从学校后门出去，拦了一辆出租车。

司机听到城北高架，皱眉：“那边这会儿堵得很啊。”

“加钱。”江临川说。

司机立刻踩油门。

车窗外的江城夜色飞快往后退。

高考倒计时的横幅、路边烧烤摊、补习机构灯箱、骑电动车回家的学生，全都在霓虹里变成一条条模糊的线。

林砚不停拨唐曼电话。

无服务。

无服务。

无服务。

第七次时，电话终于通了。

没有人声。

只有公交车报站的机械女声。

车辆转弯，请注意安全。

然后是很多人同时吸气的声音。

尖叫。

急刹。

金属撕裂。

电话里传来一声巨响。

林砚的血像被冻住。

出租车司机也听见了，脸色一变：“出车祸了？”

林砚抓着手机：“快点。”

司机没再废话，拐上辅路。

城北高架出现在前方。

夜色里，车流缓慢移动，红色尾灯连成一片。高架右侧有一段弯道，下面是正在施工的地块，围挡上贴着城市更新宣传画。

林砚远远看见 307 路公交。

它在弯道上。

车身倾斜，前半截撞穿护栏，半个车头悬在高架外。挡风玻璃碎成蛛网，车厢里灯光闪烁，人影混乱。后方车辆疯狂鸣笛，司机们下车奔跑。

林砚推门下车。

出租车还没停稳，他已经冲了出去。

江临川紧跟在后。

“林砚，别靠太近！”

林砚像没听见。

他翻过隔离栏，朝公交车跑。

刺鼻的汽油味扑面而来。

车里有人在哭，有人在敲窗，有个小孩趴在座椅边，额头都是血。林砚一眼看见唐曼。

她坐在中段靠窗位置，身体歪在扶手旁，脸色苍白，额角有血。

“妈！”

林砚冲过去。

就在他的手碰到公交车门的一瞬间，世界静止了。

鸣笛声断了。

哭喊声断了。

高架上的风也断了。

所有车辆、所有人、所有碎玻璃，都停在原地。

林砚的手按在公交车门上，指尖冰冷。

江临川在他身后三米处停住。

“别碰门。”江临川声音很低。

林砚回头。

“我妈在里面。”

“我知道。”

“那你让我别碰？”

江临川看着公交车，脸色前所未有地难看。

“因为这辆车不是刚撞的。”

林砚瞳孔一缩。

公交车车身开始发出轻微的咔咔声。

碎裂的挡风玻璃一点点复原。

悬空的车头慢慢退回护栏内。

弯曲的金属重新伸直。

血迹回到伤口里。

哭喊的人恢复坐姿。

那个额头流血的小孩重新低头玩手机。

唐曼额角的血消失，身体坐直，手里还握着备用钥匙。

整辆公交车像一段被倒放的视频，逐帧恢复成没有出事前的样子。

护栏复原。

车灯稳定。

车门打开。

司机平静地看着前方。

世界声音重新涌回。

车辆起步，请站稳扶好。

307 路公交缓缓停靠在城北高架东临时站。

车门打开。

乘客们神情正常。

唐曼低头看手机，像刚才只是普通到站。

林砚站在车门外，浑身发冷。

他看见车身侧面有一道极淡的刮痕。

刮痕下面，灰白色粉末组成了一行小字。

第三次校准完成。
