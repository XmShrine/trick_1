# 第009章 新同学知道那一分钟

林砚一整晚都在想江临川这个名字。

三模年级第三。

总分 699。

排在许清禾后面。

可直到成绩公布前，林砚对这个人没有任何印象。

这不合理。

江城七中高三年级一共十六个班，尖子生就那么一小圈。哪怕不是同班，年级前十的名字也会被老师反复挂在嘴边。谁数学满分，谁英语作文扣两分，谁物理竞赛拿奖，这些消息在高三楼里传得比食堂菜单还快。

更何况是年级第三。

林砚问过周启帆。

周启帆说：“江临川？没听过。是不是外校借考的？”

林砚又问许清禾。

许清禾翻出年级成绩单，看着那个名字沉默了几秒。

“我也没印象。”她说。

“你没印象？”

许清禾在年级前五里待了三年。

她对竞争对手的熟悉程度，比班主任对课程表还高。

“没有。”许清禾说，“但成绩单上有他，而且各科分数很完整。”

林砚看着那张纸。

江临川。

语文 123，数学 145，英语 141，物理 96，化学 97，生物 97。

完美得像一组被精心调过的数字。

“查一下学籍？”周启帆小声说。

林砚看他。

周启帆立刻举手：“我就随口一说。别这么看我，我现在看见编号都想绕路。”

许清禾把成绩单折起来：“别急。一个名字突然出现，不代表这个人突然出现。也可能是我们以前没注意。”

这句话很理性。

但说完后，她自己也没有继续写题。

第二天早读前，赵明德带着一个男生走进教室。

那一瞬间，班里所有声音都低了一点。

不是因为男生有多夸张。

恰恰相反，他看起来太自然了。

白色夏季校服，黑色书包，个子很高，头发剪得清爽，眼神懒散得像刚从午睡里被叫醒。他站在讲台旁边，视线扫过全班时，嘴角还带着一点很浅的笑。

那种笑不是讨好。

是知道自己会被注意，所以懒得装作不被注意。

赵明德敲了敲讲台：“安静一下。介绍一位新同学，江临川，之前因为家庭原因在外地借读，现在转回我们年级，接下来和大家一起备战高考。”

教室里响起细碎的议论声。

“这时候转学？”

“三模年级第三那个？”

“真的假的？”

“长得还挺……”

赵明德咳了一声，议论立刻停住。

“江临川，你坐……”他扫了一圈教室。

高三一班座位几乎固定，临时塞进一个人并不容易。

江临川忽然抬手，指向林砚后面那个空位。

“老师，我坐那儿吧。”

赵明德看了一眼：“那是刘铭的位置，他去竞赛集训请假，不一定一直空着。”

“没关系。”江临川笑了笑，“我不挑。”

他的语气温和，却有种奇怪的笃定，像他不是在请求，而是在确认已经发生的事。

赵明德皱了下眉，但还是点头：“行，先坐那里。”

江临川背着书包走下讲台。

他经过林砚身边时，脚步很轻，身上有一股淡淡的木香，不像香水，更像某种被晒过的旧纸。

林砚没有抬头。

他盯着桌面上的英语书。

可江临川在他身后停了一瞬。

很短。

短到其他人几乎察觉不到。

然后他低声说：“你比我想的镇定。”

林砚的笔尖停住。

江临川已经坐到后排。

早读开始。

英语课代表领读作文模板，全班声音拖拖拉拉。赵明德站在门口看了一会儿，确认没人说话后，才拿着成绩单离开。

林砚没有回头。

他在草稿纸上写：

江临川，三模年级第三，今日转入一班。

刚才经过时说：你比我想的镇定。

字迹正常。

他继续写：

疑似知道异常。

刚写完“疑似”，那两个字颜色浅了一点。

林砚立刻停笔。

他把“疑似知道异常”划掉，改成：

他的话缺少普通转学生语境。

这一次没有变化。

身后忽然传来一声轻笑。

很轻。

只有林砚能听见。

江临川在笑。

林砚没有回头。

他忽然意识到，对方也许能看见他在写什么。

第一节课后，江临川迅速成了全班焦点。

高考前二十天转来一个年级第三，这件事本身就足够离谱。更离谱的是，他好像对高三一班一点也不陌生。谁是课代表，谁坐哪里，哪张桌子腿不平，哪台空调出风口坏了，他都能准确避开。

一个女生问他：“你以前真没在我们班待过吗？”

江临川靠在椅背上，笑着说：“可能梦里待过。”

女生笑起来。

周启帆凑到林砚旁边，小声说：“这人有点装。”

林砚问：“你认识他吗？”

“不认识。”周启帆说，“但我现在不敢保证我的不认识是真的不认识。”

这句话让林砚看了他一眼。

周启帆苦着脸：“别夸，我也不想进步这么快。”

许清禾拿着水杯从座位上站起来。

她经过江临川桌边时，江临川忽然开口：“班长，饮水机今天没水。”

许清禾停住。

她看了一眼教室后面的饮水机。

桶里还有半桶水。

旁边同学说：“有水啊。”

江临川耸耸肩：“那可能是我看错了。”

许清禾没有说话，继续往后走。

她按下热水键。

没有水。

冷水键也没有。

饮水机嗡了一声，指示灯灭了。

全班有人笑：“还真没水？”

“新同学预言家啊。”

江临川懒洋洋地趴在桌上：“运气好。”

林砚看着他。

饮水机没水不是异常。

但江临川提前知道。

他知道得太自然。

像看见了一条别人看不见的提示。

第二节课间，林砚主动走到江临川桌前。

教室里不少人都在看。

一个是刚掉出年级前十的原尖子生，一个是突然空降年级第三的新同学。高三学生再怎么疲惫，对这种微妙的竞争也有天然兴趣。

江临川抬头：“有事？”

林砚说：“你刚才那句话什么意思？”

“哪句？”

“你比我想的镇定。”

江临川笑了：“夸你。”

“你以前见过我？”

“见过照片。”

“谁给你的？”

“成绩榜。”江临川说，“年级前十，林砚，挺有名的。可惜现在三十八了。”

周围有人倒吸一口气。

这话听着太欠。

周启帆立刻站起来：“你会不会说话？”

江临川看向他：“我说错了吗？”

“你……”

林砚抬手拦住周启帆。

他盯着江临川：“你知道我问的不是这个。”

江临川脸上的笑淡了一点。

他坐直身体，目光第一次认真落在林砚脸上。

“那你想问什么？”他声音压低，“问昨晚那一分钟？还是问为什么只有你记得？”

教室里的喧闹声像在这一刻离远了。

林砚的瞳孔微缩。

周启帆也僵住。

许清禾站在饮水机旁边，手里的水杯停在半空。

江临川像没看见他们的反应。

他从桌肚里拿出一本崭新的五三，翻到第一页，慢慢写下自己的名字。

江临川。

三个字锋利漂亮。

“别这么看我。”他说，“你昨晚闹那么大，想不知道都难。”

林砚的声音很轻：“我没告诉过任何人‘一分钟’。”

江临川笔尖一停。

然后他笑了。

这一次，笑意里多了点真正的兴趣。

“是吗？”

上课铃响了。

数学老师拿着卷子走进来，教室瞬间归位。林砚只能回到座位。

整整一节数学课，他没有写一道题。

他能感觉到身后的人偶尔抬头。

不是看黑板。

是看他。

下课铃响后，江临川拎起书包就往外走。

林砚跟了上去。

许清禾在他经过时低声说：“别单独去。”

林砚没有停。

周启帆立刻要跟，林砚回头看了他一眼。

“你留着。”

“凭什么？”

“你已经被牵进来太多。”

周启帆急了：“现在想起我了？刚才谁让我陪你疯一次？”

林砚没再解释。

江临川走得不快。

像是故意等他。

他穿过走廊，绕开下楼的人群，最后停在三号教学楼和实验楼之间的连廊。这里平时很少有人来，墙上贴着旧的社团海报，窗外是学校后操场的围墙。

林砚在他身后三米处停住。

“你知道什么？”林砚问。

江临川转身靠在窗台边：“比你多一点。”

“那一分钟是什么？”

“你现在问这个太早。”

“谁决定早不早？”

江临川看着他：“活下来的人。”

林砚的手指慢慢收紧。

江临川从口袋里摸出一张折成三角的黄纸。

那张纸很旧，边缘有细密的红色纹路，像用极细的笔画成。林砚看见它的瞬间，后颈莫名一凉。

“给你一个建议。”江临川说，“从今天开始，别再写东西。”

“为什么？”

“因为他们不怕你看见。”江临川指了指林砚的内侧口袋，“他们怕你把看见的东西教给别人。”

林砚盯着他：“他们是谁？”

江临川笑了笑。

“你最好先学会问，什么不是他们。”

这句话说完，连廊尽头传来脚步声。

林砚回头看了一眼。

没人。

再转回来时，江临川已经把那张黄纸夹在两指之间。

纸角无风自燃。

火光很小，蓝白色，没有烟。

林砚看着那团火，忽然闻到一股熟悉的味道。

白粉笔灰。

江临川轻声说：“你那一分钟，不止你记得。”

林砚心跳一停。

“还有谁？”

江临川没有回答。

火光熄灭。

他指间只剩下一点灰。

灰落在地上，拼成两个极淡的字。

别问。
