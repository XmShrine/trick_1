# 第033章 桌底刻着她的字

废弃体育馆比林砚记忆里更旧。

江城七中建校时间长，校园里有很多新旧不一的建筑。三号教学楼是旧楼，墙皮斑驳，但每天有人上课，烟火气足，旧得像一个脾气不好的老人。废弃体育馆不一样。它旧得像被学校从时间表上划掉了，连阳光照进去都显得犹豫。

铁门推开时，灰尘从门缝里扑出来。

周启帆立刻捂住鼻子：“这地方真能进去？不会塌吧？”

江临川走在最前面：“塌了正好，学校给你记烈士。”

“你嘴里能不能有句人话？”

“看心情。”

许清禾打开手电。

光束扫过馆内。

这里以前应该是篮球馆。木地板已经起翘，场线褪成浅白，篮筐只剩一个，另一个架子被拆掉，靠在墙边。看台上堆着旧课桌、坏椅子、褪色横幅和几箱不用的运动会号码布。高处的窗户蒙着灰，阳光从破损的玻璃里漏进来，照出空气里密密麻麻的尘埃。它们漂浮着，缓慢地旋转，像这座体育馆自己保存的旧记忆。

林砚走进来时，手腕微微发烫。

废弃。

体育。

十二点半。

西北角。

缺失的“馆”像一个看不见的洞，悬在他们几个人之间。

“现在做什么？”周启帆问。

许清禾说：“先确认我们为什么约在这里。”

这句话很重要。

他们记得碎片，却不记得约定的完整理由。昨晚 307 到站后，他们留下 307 代币，约定第二天来这里验证。可“验证什么”，每个人脑子里都有点模糊。

林砚说：“验证 307 代币是否还在粉笔盒下。”

周启帆愣住：“那我们为什么不在教室看？”

林砚也停住。

是啊。

如果只是验证代币，地点应该是教室。

为什么是体育馆？

他们昨晚一定还说过别的。

但那部分被修掉了。

江临川走到看台边，踢开一张倒扣的椅子：“因为这里不只是体育馆。”

周启帆立刻退后：“你又知道？”

江临川没有回答。

他伸手，从看台下方拖出一张旧课桌。

课桌很脏，桌面上刻满了名字、公式、脏话和毕业留言。桌腿一边短，拖出来时发出刺耳的摩擦声。

林砚看见那张桌子，心里忽然一跳。

“这不是我们班的桌子？”周启帆凑过去，“看着怎么这么眼熟？”

许清禾蹲下，手电照向桌侧。

桌侧贴着一张残破的标签。

高三一班。

座位号：03-17。

017。

又是十七。

林砚缓缓蹲下。

桌面上灰尘很厚，但有一小块被擦过。那块位置刻着几个字。

不是林砚的字。

是许清禾的。

她的字太好认。

横平竖直，力道均匀，哪怕用刻刀划在木头上，也像一笔一画量过。

那行字是：

如果忘了，来西北角。

许清禾的脸色变了。

“我没有刻过。”

林砚看着她。

许清禾蹲在桌边，手电光照在她脸上，让她显得比平时更苍白。她的眼神里第一次出现了近乎失控的茫然。

“至少我不记得。”她补了一句。

周启帆小声说：“会不会是另一个你刻的？”

他说完自己都觉得这话离谱，赶紧闭嘴。

可没人笑。

因为他们最近见过太多离谱的东西。

林砚用手指轻轻摸过那行刻字。

刻痕很旧。

不是昨晚刻的。

木纹边缘已经发暗，灰尘沉在笔画里，像至少存在了几年。

如果忘了，来西北角。

这不是他们昨晚第一次约这里。

他们以前来过。

或者说，某个“他们”以前来过。

许清禾忽然站起来，走向看台深处。

“我想起来一点。”她说。

林砚跟上去：“想起什么？”

“梦里有这个地方。”

体育馆深处堆着更多旧桌椅。许清禾走得很慢，像不是在寻找，而是在被某种模糊的记忆牵引。她走到看台最里面，停在一块被旧横幅盖住的墙前。

横幅上写着：

青春无悔，决胜高考。

字已经褪色。

许清禾伸手，把横幅掀开。

墙上刻满了字。

不是一个人的字。

很多人的。

有的深，有的浅，有的像学生无聊乱刻，有的像用尖锐器物匆忙划下。它们叠在一起，像一面杂乱的、沉默的证词墙。

别交卷。

不要坐 307。

四楼不是楼。

张守义记得三次。

JLC 不会毕业。

何照不能信第一次诊断。

梁秋声知道白塔。

别看黑板。

最后一句刻得最深。

深到墙皮都裂开。

林砚站在那面墙前，浑身发冷。

这些不是未来。

也不全是过去。

它们像许多次被修掉后残留的边角，被人一点点藏进这个废弃体育馆。学校以为这里废弃，所以它成了一个不被正常秩序频繁清扫的地方。越脏，越旧，越没人来，越能藏住那些不该被记得的东西。

周启帆看得头皮发麻：“这谁刻的？”

江临川淡淡说：“醒过的人。”

“他们人呢？”

江临川没有回答。

周启帆也没有继续问。

因为答案已经在墙上。

如果那些人还在，如果他们成功了，这面墙不会只剩刻痕。

林砚在墙上找到自己的名字。

不止一次。

林砚，别证明。

林砚，别坐 307。

林砚，如果你看到这里，说明你又忘了。

又。

这个字让他的胃像被什么东西攥住。

许清禾忽然伸手，按住墙上一行很浅的刻字。

那行字几乎被其他刻痕盖住。

她用手电照过去。

清禾，别让他一个人去。

许清禾的手指微微发抖。

她终于失去了平时那种近乎完美的冷静。

林砚看着她，低声说：“可能不是你刻的。”

“可这是我的字。”

“字也可能被复制。”

许清禾转头看他：“你真这么想？”

林砚沉默。

他当然不这么想。

他只是下意识想给她一个合理解释。

就像所有人给他合理解释一样。

许清禾看出了这一点。

她没有责怪，只是慢慢收回手。

“林砚。”她说，“不要用你讨厌的方式安慰我。”

这句话让林砚无法回答。

体育馆深处忽然传来啪的一声。

像篮球落地。

四个人同时转头。

空荡荡的球场中央，不知什么时候多了一个篮球。

旧的，褪色的，表面裂开几道纹。

它弹了一下。

啪。

又弹了一下。

啪。

没有人拍它。

它自己在场地中央，一下一下，缓慢跳动。

江临川脸色变了。

“别站墙边。”

“为什么？”

“这地方醒了。”

篮球停住。

场馆顶部的旧灯，一盏接一盏亮起。

惨白的灯光照亮整个废弃体育馆。

球场中央，缓缓浮现出一条白色粉笔线。

那不是球场线。

是公交站台的停车线。

下一秒，机械女声在空荡荡的体育馆里响起：

307 路临时支线，终点站到了。

请遗失记忆的乘客，到站台认领。
