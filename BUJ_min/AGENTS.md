# 极简手帐与原生 App 的同步维护

本目录的网页版与 `../../MiniBujo/` 原生 App 是同一个手帐产品的两个版本，需要同步维护。

- 修改共用功能、交互、文案、符号含义、默认值、日期处理、数据结构或导入导出行为时，必须检查另一端，并在适用时同步修改，不能只完成当前目录。
- 两端 JSON 数据格式必须保持互通；涉及数据结构的修改，需要检查两端的读取、保存、导入和导出兼容性。
- 修复布局或显示问题时，要检查另一端是否存在同类问题；按各自平台实现修复，不要求使用相同代码或完全相同的排版。
- 平台专属功能（例如 macOS 的 Sparkle 更新、原生系统通知、浏览器文件权限）只改适用平台，但必须确认另一端不受影响，并在交付说明中说明不同步的原因。
- 修改前阅读另一端的相关实现和适用指示；完成后说明分别修改了哪些端、如何验证。提交、推送或发布仍按用户授权和各仓库规则执行。

同一工作区内的对应路径：`../../MiniBujo/`。如果另一端不在当前工作区，应先查找或向用户说明，不能假定已经完成同步。
